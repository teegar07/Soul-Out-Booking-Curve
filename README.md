# Soul Out Booking Curve

Soul Out 活動預售進度與訂位曲線追蹤工具。

## Vol.11

- 活動日：2026-09-19
- 最終入場目標：160 人
- 初始預售：25 張（2026-08-19）
- Vol.9 現場票：22 張
- Vol.10 現場票：30 張
- 歷史平均現場票：26 張
- 目前建議拆分：134 張預售 + 26 張現場票 = 160 人

## 模型

Vol.9 與 Vol.10 的預售資料先依「距離活動日天數」標準化，再計算兩場的同期平均累積比例。Vol.11 目標曲線以歷史平均比例乘上建議預售目標。

因此活動當天才發生的現場票不會混入預售訂位進度。

## 使用

直接開啟 `index.html`。輸入目前預售票數與追蹤日期後按「更新進度」，資料會保存在瀏覽器 localStorage。

啟用 GitHub Pages 後，可直接作為手機／桌面 Web Dashboard 使用。
